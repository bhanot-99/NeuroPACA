  2. Local Embedding Layer Evaluation:
      • Observation: Voice-standalone uses fastembed with BAAI/bge-small-en-v1.5 (~10.7 ms latency, 0 GPU

      monopolize the local 4GB GPU card. Keep fastembed / bge-small-en-v1.5 for the millisecond-scale
      Layer 1 intent scan. If deeper document RAG is added, offload Nemotron-3-Embed calls to an API or
      run CPU-quantized chunking.
